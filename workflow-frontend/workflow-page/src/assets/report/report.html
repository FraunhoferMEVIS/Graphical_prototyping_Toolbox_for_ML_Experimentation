Evaluation study description

Study design

  • For this binary classification task, the risk of in-hospital mortality needs to be predicted.
  • The evaluation study is based on a single independent test data set with \(n=3540\) observations (20% of entire dataset).
  • The empirical prevalence of in-hospital deaths in the test set is \(12.5\%\) (\(n_1=444\) cases).

Models

  • In total, \(4\) different models are being evaluated.
  • All models have been tuned via cross-validation, independently of the test data.
  • Different subsets of these models are used in the primary and secondary analyses specified below.
  • Model overview:
Model Description mlflow_id
LR Logistic Regression 3960d6e9601f46cabff72e359d364826
RF Random Forest f299b0033c2a4779a39f9efb3c478815
LR_bal Logistic Regression (balanced) 8f4c34f3a72a4d1cb42390a060c3c67c
RF_bal Random Forest (balanced) 67bd92910a034ab5ad70814b70c7cfd2

Metrics

  • Two performance metrics have been selected for evaluation.
  • The main focus will be on the primary metric.
  • In the sensitivity analyses, the other metric will be employed to check the sensitivity of results w.r.t. different metrics.
  • Metric overview:
Metric Description Type Primary
bAcc Balanced classification accuracy class TRUE
AUPRC Area under precision recall curve probability FALSE

Hypotheses

Primary hypothesis

(A)
  • Scientific question: Does the tuned Random Forest (RF) model outperform the tuned Logistic Regression (LR) model?
  • Statistical hypotheses:
Code 
hypothesis_table <- readr::read_csv(file.path(dir, paste0(date, "_hypothesis_table.csv")), show_col_types=FALSE) 
hypothesis_table %>% 
  dplyr::filter(ID=="A") %>%

ID Type Symbol Hypothesis

A alternative \(H_{A1}\) \(\vartheta(\text{RF}) > \vartheta(\text{LR})\)

Secondary hypotheses

(B)
  • Scientific question: Do “balanced” versions of Logistic Regression and Random Forest outperform the respective standard implementations?
  • Statistical hypotheses:
ID Type Symbol Hypothesis
B null \(H_{B0}\) \(\vartheta(\text{RF{\_}bal}) \leq \vartheta(\text{RF}) \ \wedge \ \vartheta(\text{LR{\_}bal}) \leq \vartheta(\text{LR})\)
B alternative \(H_{B1}\) \(\vartheta(\text{RF{\_}bal}) > \vartheta(\text{RF}) \ \vee \ \vartheta(\text{LR{\_}bal}) > \vartheta(\text{LR})\)

Hypothesis overview

ID Type Symbol Hypothesis
A null \(H_{A0}\) \(\vartheta(\text{RF}) \leq \vartheta(\text{LR})\)
A alternative \(H_{A1}\) \(\vartheta(\text{RF}) > \vartheta(\text{LR})\)
B null \(H_{B0}\) \(\vartheta(\text{RF{\_}bal}) \leq \vartheta(\text{RF}) \ \wedge \ \vartheta(\text{LR{\_}bal}) \leq \vartheta(\text{LR})\)
B alternative \(H_{B1}\) \(\vartheta(\text{RF{\_}bal}) > \vartheta(\text{RF}) \ \vee \ \vartheta(\text{LR{\_}bal}) > \vartheta(\text{LR})\)

Statistical methods

  • Confidence intervals and p-values are computed with the statistical bootstrap (percentile method).
  • When multiple comparisons are conducted for a single hypotheses, a Bonferroni adjustment is utilized.

    delta = 0,
